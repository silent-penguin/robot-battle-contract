# Robot Battle — Документация движка

## Обзор

**Robot Battle** — пошаговая арена, в которой PHP-роботы сражаются на сетчатой карте.
Каждый участник реализует интерфейс `RobotInterface`, загружает файл на платформу — и платформа автоматически запускает бои.

---

## Быстрый старт

```php
<?php

use RB\Contract\Action\ActionInterface;
use RB\Contract\Action\AttackAction;
use RB\Contract\Action\MoveAction;
use RB\Contract\Action\PickupAction;
use RB\Contract\Action\ShootAction;
use RB\Contract\Action\UseItemAction;
use RB\Contract\Action\WaitAction;
use RB\Contract\BattleInfo;
use RB\Contract\Context;
use RB\Contract\Item\ItemType;
use RB\Contract\Map\Direction;
use RB\Contract\Robot\RobotInterface;

final class MyRobot implements RobotInterface
{
    private ?BattleInfo $info = null;

    public function onBattleStart(BattleInfo $battleInfo): void
    {
        $this->info = $battleInfo;
        // Можно запомнить: mapWidth, mapHeight, maxTurns, stepTimeoutMs, и т.д.
    }

    public function step(Context $context): ActionInterface
    {
        $self = $context->self;
        $pos  = $self->position;

        // Подобрать предмет под ногами
        foreach ($context->visibleTiles as $tile) {
            if ($tile->position->isEquals($pos) && $tile->hasItem()) {
                return new PickupAction(store: true);
            }
        }

        // Атаковать соседнего врага
        foreach ($context->visibleEnemies as $enemy) {
            foreach (Direction::cases() as $dir) {
                if ($dir->apply($pos)->isEquals($enemy)) {
                    return new AttackAction($dir);
                }
            }
        }

        // Использовать аптечку, если мало HP
        if ($self->health < 40) {
            foreach ($self->inventory as $item) {
                if ($item->type === ItemType::Medkit) {
                    return new UseItemAction(ItemType::Medkit);
                }
            }
        }

        // Идти в случайном направлении
        $dirs = Direction::cases();
        
        return new MoveAction($dirs[array_rand($dirs)]);
    }
}
```

## Параметры карты и боя

Ниже представлены базовые параметры карты и боя. Все данные могут быть изменены во время отдельных матчей или турниров.

| Параметр          | Значение                                                                                  |
|-------------------|-------------------------------------------------------------------------------------------|
| Размер карты      | 25 × 25 клеток                                                                            |
| Система координат | (0, 0) — верхний левый угол; X растёт вправо, Y — вниз                                   |
| Начальное HP      | 100                                                                                       |
| Начальная атака   | 10                                                                                        |
| Начальная защита  | 5                                                                                         |
| Дальность обзора  | 10 клеток (радиус луча)                                                                   |
| Размер инвентаря  | 5 предметов                                                                               |
| Максимум ходов    | задаётся при создании боя                                                                 |
| Таймаут на ход    | **50 мс** (измеряется после возврата из `step()`)                                         |
| Лимит памяти      | **65 536 байт** (heap-память экземпляра, измеряется клонированием после каждого `step()`) |

## Порядок исполнения хода

Все роботы ходят **одновременно**: каждый ход каждый робот видит одно и то же состояние поля до того, как чьи-либо действия применены.

Внутри одного хода действия исполняются в три фазы:

| Фаза | Действия              | Примечание                                                    |
|------|-----------------------|---------------------------------------------------------------|
| 1    | `MoveAction`          | Роботы перемещаются; карта обновляется                        |
| 2    | `AttackAction`, `ShootAction` | Атаки разрешаются по **позициям начала хода**         |
| 3    | `PickupAction`, `UseItemAction`, `DropItemAction`, `WaitAction` | Всё остальное |

**Важно для атак (фаза 2):** атака и выстрел проверяют позицию цели на **начало хода** — до того, как применились перемещения фазы 1. Это означает, что уйти от удара или пули, которая уже «была выпущена», нельзя: если противник решил атаковать вас в ту клетку, где вы стояли в начале хода, вы получаете урон, даже если сами в этот же ход решили уйти.

**Следствие:** если робот A атакует и убивает B в фазе 2, то действие B из фазы 3 (если оно не было перемещением) всё равно применяется — оно было поставлено в очередь до того, как B погиб.

---

## Разрешение конфликтов

Так как все роботы принимают решения одновременно, возможны следующие конфликты:

- **Два робота нацелились на одну и ту же клетку (`MoveAction`)** — оба хода отменяются, никто не двигается.
- **Робот хочет войти в клетку, занятую другим роботом, который не двигается** — ход отменяется (клетка непроходима).
- **Робот атакует клетку, куда противник уходит в этот же ход** — атака **попадает**: цель проверяется по позиции начала хода, а не по конечной.
- **Робот умер в фазе 2** — его действие из фазы 3 игнорируется; `step()` у него в следующих ходах не вызывается.

## Действия

Метод `step()` должен вернуть ровно **одно** действие из следующих:

### `MoveAction(Direction $direction)`
Переместить робота на одну клетку в заданном направлении.

- Движение отменяется, если целевая клетка — стена или занята другим роботом.
- Движение на клетку с предметом разрешено (предмет не подбирается автоматически).

```php
return new MoveAction(Direction::Up);
// Direction: Up | Down | Left | Right
```

### `AttackAction(Direction $direction)`
Удар по соседней клетке в указанном направлении.

- Работает только если в целевой клетке **стоял живой враг в начале хода** (до перемещений).
- Если клетка пустая — действие тихо игнорируется.
- **Формула урона:** `max(1, атака_нападающего − защита_цели)`

```php
return new AttackAction(Direction::Right);
```

### `ShootAction(Direction $direction, ?ItemType $preferredWeapon = null)`
Выстрел по прямой в заданном направлении.

- **Требует оружие (Gun или SniperRifle) в инвентаре.** Если оружия нет — выполняется обычный `AttackAction` на 1 клетку.
- Снаряд летит прямо, пока не упрётся в стену или не достигнет максимальной дальности.
- Попадание проверяется по **позициям начала хода** (до перемещений фазы 1).
- Дальность: `gun->range` (3–7 клеток, зависит от конкретного оружия) + бонус от Scope в инвентаре (+3).
- **Формула урона:** `max(1, атака − защита_цели − 2)` (-2 штраф за дальность).
- Через `$preferredWeapon` можно указать предпочтительный тип оружия; если его нет — движок возьмёт любое доступное.

```php
// Убедиться, что Gun есть в инвентаре:
foreach ($context->self->inventory as $item) {
    if ($item->type === ItemType::Gun) {
        return new ShootAction(Direction::Down, ItemType::Gun);
    }
}
```

### `PickupAction(bool $store = false)`
Поднять предмет с клетки, на которой стоит робот.

- Если предметов нет — действие игнорируется.
- `store: false` (по умолчанию) — предмет применяется **немедленно** (HP/атака/защита обновляются).
- `store: true` — предмет кладётся в инвентарь (максимум 5 слотов). Если инвентарь полон, предмет применяется немедленно.
- **Оружие (Gun, SniperRifle)** можно только положить в инвентарь (`store: true`). Если инвентарь полон — предмет остаётся на карте.
- **Scope** не даёт немедленного эффекта. Его нужно положить в инвентарь (`store: true`) — только тогда он работает.

```php
return new PickupAction();            // применить сразу
return new PickupAction(store: true); // положить в инвентарь
```

### `UseItemAction(ItemType $itemType)`
Использовать предмет из инвентаря.

- Если предмета нет в инвентаре — действие тихо игнорируется.
- После использования предмет удаляется из инвентаря, и освободившийся слот сразу доступен.
- **Scope** — пассивный предмет: `UseItemAction(Scope)` ничего не делает, Scope остаётся в инвентаре и продолжает работать.

```php
return new UseItemAction(ItemType::Medkit);
return new UseItemAction(ItemType::Shield);
```

### `DropItemAction(ItemType $itemType)`
Выбросить предмет из инвентаря на текущую клетку.

- Если предмета нет в инвентаре — действие тихо игнорируется.
- Если на текущей клетке уже лежит предмет — действие тихо игнорируется.
- После выбрасывания слот в инвентаре освобождается, предмет остаётся на карте и может быть подобран любым роботом.

```php
return new DropItemAction(ItemType::Gun); // освободить слот, пожертвовав оружием
```

### `WaitAction()`
Пропустить ход. Ничего не происходит.

```php
return new WaitAction();
```

## Предметы

Предметы появляются на карте в начале боя и после подбора не восстанавливаются.

### Medkit (аптечка)
- **Немедленный эффект:** +20 HP (максимум 100).
- **Из инвентаря** (`UseItemAction(ItemType::Medkit)`): то же самое.

### Shield (щит)
- **Немедленный эффект:** +3 к защите (постоянно, суммируется).
- **Из инвентаря** (`UseItemAction(ItemType::Shield)`): то же самое.

### Scope (прицел)
- **Пассивный предмет:** работает, пока находится в инвентаре.
- **Бонусы пока в инвентаре:** +5 к дальности обзора, +3 к дальности выстрела.
- Подбирать нужно с `store: true`; `store: false` никакого эффекта не даёт.
- `UseItemAction(Scope)` — no-op: Scope остаётся в инвентаре.
- Чтобы убрать эффект — выбросить через `DropItemAction(ItemType::Scope)`.

### Gun (пистолет)
- **Хранится в инвентаре**, не применяется «сразу».
- Нужен для `ShootAction`. Дальность выстрела: `$item->range` (значение 3–7).
- Без Gun (или SniperRifle) в инвентаре `ShootAction` деградирует до обычного удара на 1 клетку.

### SniperRifle (снайперская винтовка)
- **Хранится в инвентаре**, не применяется «сразу».
- Работает так же, как Gun, но с бо́льшей дальностью: `$item->range` (обычно 7).
- Используется для `ShootAction` — через `$preferredWeapon` можно явно запросить конкретное оружие.

## Поле зрения (FOV)

- Стандартный радиус: **10 клеток** (ray-casting от позиции робота).
- Стены блокируют лучи — клетки за стенами не видны.
- **`$context->visibleTiles`** — плоский список объектов `Tile`. У каждого:
  - `$tile->position->x`, `$tile->position->y` — абсолютные координаты.
  - `$tile->type` — `TileType::Empty | TileType::Wall | TileType::Item | TileType::Robot`.
  - `$tile->item` — объект `Item|null`, если на клетке лежит предмет.
  - `$tile->hasItem()` — `true`, если предмет есть.
  - `$tile->isPassable()` — `true`, если клетка проходима (не стена и не занята роботом).
  - `$tile->isWall()` — `true`, если стена.
  - `$tile->isEmpty()` — `true`, если тип `Empty`.
- **`$context->visibleEnemies`** — массив `Position[]` позиций живых врагов в зоне видимости.
- **`$context->viewRange`** — текущий радиус обзора (с учётом бонуса от Scope в инвентаре).

> **Совет:** используйте `visibleTiles` для построения собственной карты в памяти — лучи открывают новые клетки каждый ход, и со временем вы узнаете расположение стен.

---

## Лимит времени

- `step()` должен вернуть действие не позднее чем через **50 мс**.
- Время измеряется **после возврата** из `step()` (бесконечный цикл заморозит поток, а не прервётся).
- При нарушении лимита ход пропускается (как `WaitAction`).

---

## Лимит памяти

- Максимум **65 536 байт** (64 КБ) на внутреннее состояние робота.
- Измеряется как **heap-память, выделенная под свойства экземпляра**, через клонирование робота после каждого `step()`.
- При превышении ход пропускается.
- Статические свойства класса в лимит не входят — учитываются только данные конкретного экземпляра.

---

## Обнаружение зацикливания

Движок отслеживает **последние 10 позиций** каждого живого робота.
Если в этом окне **2 или менее уникальных позиций** — робот считается «застрявшим» (бесконечный пейс, колебание туда-обратно).

**Последствия:**
- Зациклившийся робот исключается из боя (поражение).
- Если застряли все роботы одновременно — ничья.
- Если среди незациклившихся роботов несколько живых — побеждает тот, у кого больше HP.

> **Практический совет:** любая логика «иду до стены, разворачиваюсь, иду обратно» попадает под это правило. Добавляйте рандомизацию или смену цели.

## Условия победы

| Ситуация                   | Результат                                      |
|----------------------------|------------------------------------------------|
| Остался один живой робот   | Он победитель                                  |
| Исчерпан лимит ходов       | Победитель — робот с наибольшим HP             |
| Зациклился один из роботов | Незациклившийся побеждает                      |
| Зациклились все роботы     | Ничья                                          |
| Равное HP при лимите ходов | Победитель — первый в списке с максимальным HP |

## Справочник интерфейсов

### `BattleInfo` — данные перед боем

| Поле                   | Тип   | Значение                      |
|------------------------|-------|-------------------------------|
| `$mapWidth`            | `int` | Ширина карты (25)             |
| `$mapHeight`           | `int` | Высота карты (25)             |
| `$maxTurns`            | `int` | Максимальное количество ходов |
| `$inventorySize`       | `int` | Размер инвентаря (5)          |
| `$stepTimeoutMs`       | `int` | Таймаут на ход в мс (50)      |
| `$startRobotHealth`    | `int` | Начальное HP (100)            |
| `$startRobotAttack`    | `int` | Начальная атака (10)          |
| `$startRobotDefence`   | `int` | Начальная защита (5)          |
| `$startRobotViewRange` | `int` | Начальный радиус обзора (10)  |
| `$memoryLimitBytes`    | `int` | Лимит памяти в байтах (65536) |

### `Context` — данные каждый ход

| Поле              | Тип          | Описание                                         |
|-------------------|--------------|--------------------------------------------------|
| `$self`           | `RobotInfo`  | Информация о вашем роботе                        |
| `$visibleTiles`   | `Tile[]`     | Все видимые тайлы                                |
| `$visibleEnemies` | `Position[]` | Позиции видимых врагов                           |
| `$currentTurn`    | `int`        | Текущий номер хода                               |
| `$viewRange`      | `int`        | Текущий радиус обзора (с учётом бонуса от Scope) |

### `RobotInfo` — ваш робот

| Поле         | Тип        | Описание                       |
|--------------|------------|--------------------------------|
| `$name`      | `string`   | Имя робота                     |
| `$position`  | `Position` | Текущая позиция (`->x`, `->y`) |
| `$health`    | `int`      | Текущее HP                     |
| `$attack`    | `int`      | Текущая атака                  |
| `$defense`   | `int`      | Текущая защита                 |
| `$inventory` | `Item[]`   | Предметы в инвентаре           |

## Правила для кода

1. **Один файл — один класс**, реализующий `RobotInterface`.
2. **Конструктор без аргументов** — движок инстанциирует класс как `new YourRobot()`.
3. **Запрещённые функции:** `exec`, `system`, `shell_exec`, `passthru`, `popen`, `proc_open`, `eval`, `assert`, `pcntl_exec`, файловые операции (`file_put_contents`, `file_get_contents`, `fopen`, `unlink`, `rename`, `mkdir`, `rmdir` и др.), сетевые функции (`fsockopen`, `pfsockopen`, `curl_init`, `curl_exec`, `curl_multi_exec`, `socket_create`, `socket_connect`, `stream_socket_client`, `stream_socket_server`, `http_get`, `http_post`, `http_request` и др.), `dns_get_record`, `gethostbyname`, `gethostbynamel`, `class_exists`.
4. **Сторонние библиотеки** не допускаются.
5. **Сеть** использовать нельзя.
